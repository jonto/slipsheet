Slipsheet — dist bundle (production path)

Same demo as basic.html, but loads viewer.min.{js,css} from packages/viewer/dist/ instead of src/. Verifies the build output is functionally equivalent to the source.

Download tracemonkey.pdf (6 pages)

When this project ships to npm, adopters get dist/viewer.min.{js,css} by default via the main + style fields in package.json. The unminified source remains available under ./src/ for adopters who prefer it (debugging, bundling alongside their own code, etc).
