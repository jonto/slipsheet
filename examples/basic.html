Slipsheet — basic example

Phase 1 first slice: discovery + lazy PDF.js + first-page render.

Below is the markup contract — a plain div with data-* attributes and an embedded download-link fallback. Slipsheet.init() finds it, lazy-loads PDF.js, and renders the first page.

Download tracemonkey.pdf (6 pages)

If JavaScript is disabled, or PDF.js fails to load, the embedded download link above remains visible. Progressive enhancement; the content never depends on JS.

The PDF used is Mozilla's canonical PDF.js test file (tracemonkey paper), bundled at ./sample.pdf for offline development.
